# Mintarr project pause

Effective date: 2026-07-26  
Status: **PAUSED INDEFINITELY**

The owner has paused Mintarr development and does not intend to spend further
project time on it in the current planning horizon.

## What the pause means

- No feature development, roadmap execution or routine dependency work.
- No active Mintarr deployment.
- The associated Lidarr/music automation stack is stopped and configured not
  to restart automatically.
- Existing issues and pull requests may remain for historical context, but do
  not imply an active delivery commitment.
- GitHub remains the declared `GITHUB-COLLAB` writer-of-record and Forgejo
  remains its read-only recovery replica. The pause does not change the
  repository profile or trigger another migration.
- Source, branches, tags, metadata exports, backups and recovery evidence are
  retained.

Operational details for the stopped self-hosted services live in the private
mediastack repository under
`docs/MINTARR_MUSIC_STACK_PAUSE_2026-07-26.md`.

## Allowed maintenance while paused

Only narrowly scoped preservation work should occur:

- critical secret revocation or security remediation;
- backup, metadata-export and restore verification;
- mirror-drift repair;
- documentation needed to preserve safe recovery;
- changes required to prevent unintended execution or cost.

These actions are maintenance, not a restart of product development.

## Resume gate

Resuming Mintarr requires an explicit owner decision and a reviewed plan that:

1. revalidates the product goal and whether the project should continue;
2. reviews open security and dependency advisories;
3. verifies GitHub/Forgejo parity and metadata backups;
4. reviews the private mediastack resume dependencies and credentials;
5. selects a small next milestone instead of implicitly resuming the old
   roadmap;
6. updates this document, the README and roadmap status in the same change.

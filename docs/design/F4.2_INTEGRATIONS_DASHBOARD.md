# F4.2 — Integrations Dashboard

> **Type:** Design document
> **Version:** 1.0 — 2026-05-31
> **Status:** Implemented — server-rendered Integrations tab consuming `/dashboard/v1/connectors`
> **Related:** [F4.1 Static Connector Registry](F4.1_STATIC_CONNECTOR_REGISTRY.md), [CONNECTOR_PLUGIN_ARCHITECTURE.md](CONNECTOR_PLUGIN_ARCHITECTURE.md), [CONNECTOR_MANIFEST_v1.md](../specs/CONNECTOR_MANIFEST_v1.md)

---

## 1. Goal

F4.2 gives operators a dashboard view of the connector registry implemented in F4.1.

The dashboard should answer:

- Which source, verifier, and output integrations exist?
- Is each integration installed, enabled, and healthy?
- Which required hard-gate verifiers are missing or blocked?
- What environment variables, docker service/profile hints, and docs link apply?

## 2. Non-goals

- No enable/disable controls. F4.3 owns connector config persistence and mutation endpoints.
- No secret display. Environment variable names are visible; values are never surfaced.
- No app-managed install or update actions.
- No dynamic plugin loading.
- No rewrite of the server-rendered dashboard shell.

## 3. UI shape

Adds a tabbed dashboard surface:

- **Records**: the existing queue/records workflow.
- **Integrations**: grouped connector inventory.

The summary cards remain focused on operator action. Connector detail moves into the Integrations view.

The Integrations view groups connectors by `kind`:

- Sources
- Verifiers
- Outputs

Each connector row/card shows:

- display name and connector id
- health status
- installed/enabled/mode
- detected version and minimum supported version when available
- required flag
- required/optional environment variable names
- docker service and compose profile hints
- last check time and last error
- docs link

Required missing/blocking connectors are visually emphasized.

## 4. Backend use

The UI consumes the existing F4.1 endpoint:

```text
GET /dashboard/v1/connectors
```

F4.2 also reuses connector health in the existing stack summary where the connector response is already available to the dashboard shell.

## 5. Tests

Implemented dashboard tests cover:

- HTML shell contains the Integrations view and tab controls.
- The dashboard JS fetches `/dashboard/v1/connectors`.
- Connector details are rendered through the existing HTML shell.

F4.1 endpoint tests continue to cover auth and JSON shape.

## 6. Deferrals

F4.3 adds:

- `connector_config` table
- enable/disable controls
- dry-run/import mode controls
- mutation endpoint auth/audit
- hard-gate disable protection

F4.4 adds install guidance polish if the F4.2 information surface proves useful during dogfood.
